# Security Policy

This repository contains GIS practical exercise data (vector/raster layers,
a QGIS project, and a written report) and is not software intended to run
as a service, so the typical vulnerability surface does not apply.

## Reporting a concern

If you find something in this repository that could pose a security or data-
integrity risk, please open a [GitHub Issue](../../issues) describing it.

## Supported versions

Only the latest version of this repository is actively maintained.
